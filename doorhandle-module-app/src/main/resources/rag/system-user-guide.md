# 企业级集装箱门把手盖多智能体协同缺陷检测平台使用手册知识库

## 系统定位

系统名称为“企业级集装箱门把手盖多智能体协同缺陷检测平台”，用于集装箱门把手盖工业缺陷检测，覆盖图像采集、模型检测、检测记录、质检复核、缺陷证据、工单追溯、批次追溯、模型管理、设备管理、人员管理和智能助手。

推荐流程是上传图片、派发检测、启动模型检测、分派校验并核对模型结果。检测和校验记录可在工单追溯和批次追溯中查看。

## 检测业务

检测业务包含图片上传、检测任务列表、校验任务列表、我的任务、单图检测与对比和检测记录。

图像采集上传用于上传门把手原图，创建检测任务，并补充批次号、工单号、采集设备、采集人员等追溯字段。

主管从「待派检测」选择原图批次并派发，在「检测任务列表」查看检测进度，在「校验任务列表」分派校验。员工在「我的任务」选「待我检测」启动模型，选「待我校验」核对原图和标注图并提交结论。

「单图检测与对比」用于选择模型和置信度阈值，执行单张图片的检测或双模型对比。

检测记录用于查询历史检测任务，查看检测类别、缺陷位置、置信度、严重等级、检测图片证据和报告。

## 质检追溯

质检追溯用于按工单或批次查询，报告在「报告与审批」办理。

工单追溯用于按工单号查看检测任务、图片采集记录、模型检测结果、质检复核记录、操作人员、设备来源、缺陷证据和报告。

批次追溯用于按批次号查看检测总量、缺陷数量、缺陷类型分布、异常设备、异常模型和批次质量结论。

## 模型中心

模型中心包含模型管理和上传模型。

模型管理用于查看模型列表、版本、校验状态、发布状态、默认模型、使用统计和操作日志。生产检测建议只使用已校验并发布的模型。

上传模型用于导入新模型版本。上传后应先执行校验，再发布模型，最后根据需要设置为默认模型。

## 产线资源

产线资源包含设备管理、设备使用记录、人员管理。

设备管理用于维护采集设备、检测设备、设备编号、设备位置、在线状态、负责人和维护状态。

设备使用记录用于查看设备调用、采集、检测和维护记录，排查某台设备是否频繁产生异常结果。

人员管理用于维护采集人员、质检人员、维修人员和管理员信息，支撑操作日志和质量责任追溯。

## 智能助手

智能助手可以帮助用户查询系统功能入口、解释模块用途、查询有权限查看的质检记录、解释工单或批次追溯操作方式、说明模型管理流程和给出下一步操作建议。

可询问如何查看检测和校验进度、如何分派校验、模型管理在哪里或怎样查看工单追溯。

系统说明的语义检索源码默认接入 Qdrant / BGE-M3；查询重写和 rerank 按配置及候选数量决定是否调用。向量没有返回可用候选时，只能在已加载的系统片段上降级为关键词检索；保全启动不自动加载新手册，可能没有这份降级上下文。用户知识资料另按当前账号、当前版本和生命周期核对，并保留资料编号、版本和段落引用。部署与迁移状态可从本机部署回执核对。

## 常见问题

登录后看不到数据时，先清空筛选条件并刷新页面，再检查后端服务、数据库连接和账号权限。

首次验收时，如果没有工单、批次或质检数据，请运维核对本机部署回执中的数据库迁移结果。隔离验收库需要的业务预置数据由运维按验收方案准备。启动配置 `APP_BUSINESS_SEED_ENABLED` 保持 `false`。

检测任务一直未完成时，应检查推理服务、远程检测服务、OSS 图片路径和模型状态。

「待我校验」没有数据时，可核对主管是否已分派、任务是否完成检测以及当前筛选条件。

工单追溯或批次追溯查不到结果时，应确认工单号或批次号准确，且上传图片时已绑定追溯字段。

模型重新校验失败时，应检查模型文件是否存在、格式是否正确、元数据是否完整、推理环境是否兼容。
