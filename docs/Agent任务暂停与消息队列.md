# Agent 任务暂停、消息排队与运行中引导

2026-10-17，`java-cloud`。主站 Vue 与独立 React/AG-UI 使用同一套后端对话控制。功能默认关闭，本轮未在 ECS 迁移或发布。

## 开源参考及兼容性

参考项目内 DeepSeek Harness 快照 `86a40220` 的 [Agent API](https://github.com/deepseek-ai/deepseek-harness/blob/86a40220/packages/core/agent/README.zh.md) 与 [运行类型](https://github.com/deepseek-ai/deepseek-harness/blob/86a40220/packages/core/agent/src/runtime-types.ts)。其 `followup` 表示下一轮输入，`steer` 表示下一执行步骤引导，`inject` 不主动唤醒，取消可选择保留 inbox。该快照公开的实时 Agent API 没有通用的 `pause()/resume()` 对；恢复持久会话与继续内存中的暂停执行是不同能力。

参考仓库为 MIT（Copyright 2026 DeepSeek），本轮查询上游未归档且仍有更新。只参考交互和语义，不复制其源码，也不接入第二套执行框架。当前 AgentScope Java 为 2.0.4；已核对本地依赖，没有直接采用较新文档中的 `AgentSession` 接口。本项目使用现有 SDK middleware，在主 Agent 的模型与工具安全切点等待、补充输入并重新鉴权。

## 使用方式

- **暂停任务**：先显示等待安全切点，真正到达切点后才显示已暂停。**继续任务**仍使用原执行与原运行编号。
- 输入框上方展示紧凑待发列表，顺序为先提交先展示；右侧提供**引导、删除、更多**。
- **引导**：把选中的下一轮待发消息转为本轮补充要求，保留消息编号、来源入口和原有效期。校验当前任务编号及消息版本；不存在可引导任务时禁用。超过 4000 字符需要先编辑。
- **删除**：撤回尚未领取的本人消息。**更多**包含**编辑消息、关闭排队**；编辑保存需要当前版本，冲突保留草稿。
- **关闭排队**：本浏览器标签页内、按会话保存的发送偏好；已有待发消息继续处理，不批量删除或中断任务。存在执行或待发消息时阻止新增普通排队发送，保留草稿；显式引导仍可使用。提示区可**开启排队**。这是发送偏好，不是跨浏览器共享的服务端权限。
- 发送方式还可选择下一轮或运行中引导。没有活动任务时，引导输入作为下一轮普通消息；错过最后切点的引导也转入下一轮，并记录回退。
- **取消任务**需要明确确认，只取消本轮，保留已有排队消息，后续可继续执行。若要阻止后续消息，先逐条撤回。已完成的工具操作不会回滚。

暂停只能等当前模型调用、工具批次或专业 Agent 委派结束后的主 Agent 安全切点，不能立即冻结子进程。单次运行总时限 30 分钟，包含暂停时间；服务重启、超时或取消后不能继续原 SDK 执行。暂停期间运行日志仍为 RUNNING，由单独控制阶段与事件区分。

## 数据、调度与权限

V36 增加 `agent_conversation_input_owner`、`agent_conversation_input` 和 `agent_conversation_input_audit`。账号行锁保护配额、编辑、引导转换、领取和审计；消息 UUID、会话执行槽唯一约束与版本校验防止重复操作。原始请求模式用于不确定提交的幂等核对，转换不会创建第二条输入。

每账号最多 16 条等待/执行中消息，每次运行最多 6 条等待/已交付引导。待发消息 15 分钟有效，不因编辑或引导延长；每实例最多两个后台会话执行线程。普通消息按会话顺序领取，运行中或暂停时等待。跨实例可读运行并保存输入，但暂停/继续必须由持有实时执行的实例处理。后台执行保留 CHAT/AGUI 来源。

接口及后台调度都验证稳定用户 ID、会话归属和当前账号身份。模型/工具切点重新核对账号存在、用户名及允许角色；暂停后角色变化会拒绝继续。当前用户表没有独立的“停用”字段。引导以用户消息加入上下文，不改变系统提示、工具白名单或人工确认规则；“已交付”不表示模型必然遵从。

领取、交付、撤回、过期后清空队列表正文；实际用户对话保存在既有历史。审计仅保存动作、消息编号、版本与正文摘要，运行事件不记录引导正文。审计写失败回滚相应队列变更及同事务历史追加。失败不会自动重试，页面断网不会重复 POST；未知提交结果的手动重试沿用请求编号。

启动后仅恢复仍在原有效期内的 QUEUED 消息，不重放 STARTED 或已交付消息；异常遗留 STARTED 到期终结。后台执行依据重新查询的角色建立临时内部身份，不保存浏览器 JWT 或密码。关闭页面后已提交的后台消息仍会处理。

## 启用与回退

先备份业务数据库，确认既有会话表与 V16 运行日志迁移已具备，再在同一个业务库执行：

```text
sql/mysql/migration-V36-conversation-inbox.sql
```

App classpath 副本为 `doorhandle-module-app/src/main/resources/db/migration-V36-conversation-inbox.sql`，两份应逐字节一致。启动不自动应用这次迁移。

```dotenv
AGENT_RUN_JOURNAL_ENABLED=true
AGENT_CONVERSATION_CONTROL_ENABLED=true
```

同时发布后端及两套前端。已启用但缺表或缺运行日志时启动失败，避免静默丢消息。关闭开关并重启可回到原聊天流程；保留表及审计，不自动删表。回退前等待或撤回待发消息，正在执行的 SDK 状态不能跨重启保留。新前端对旧后端/关闭开关环境走原聊天入口，不显示控制面板。
