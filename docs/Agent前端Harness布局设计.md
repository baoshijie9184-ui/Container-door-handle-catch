# Agent 前端 Harness 布局设计

更新：2026-10-16，`java-cloud`。按用户要求，Agent 前端持续参照本地 DeepSeek Harness 的布局和交互，在现有 Vue 主站与 React 独立聊天中实现。

## 参考依据

已阅读 `deepseek-harness` 的 `ui-layout`、`ui-conversation` 文档及 AppFrame 样式。本地参考提交 `86a40220`，官方仓库为 [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)。仓库处于开发者预览，说明中提示可能出现不兼容变更；许可证为 MIT，版权属于 DeepSeek，原仓库许可证保持完整。

本轮参考左侧会话、居中正文、右侧按需工作面板的结构，以及侧栏折叠后保留快捷入口、窄屏优先保护正文的交互。新增组件在现有框架中自行实现，未复制 Harness 源文件或引入其运行时，没有新增依赖。

## 主站 Vue

入口仍为“Agent 智能系统 → 智能对话助手”。聊天头部增加“展开工作面板”，原有诊断、重试、业务导航及会话操作保留。

| 区域 | 设计 |
| --- | --- |
| 左侧 | 沿用本人会话、项目和搜索，置顶标识改用现有开源图标 |
| 中间 | 保留当前会话、消息与输入，白色正文、浅色用户消息，底部输入区继续固定 |
| 右侧工作区 | 当前会话及 Skills、MCP、个人记忆、执行与调研入口；执行入口携带当前会话编号 |
| 右侧最近执行 | 手动刷新本会话最近运行，只展示已读取的最近 8 个服务器事件及实际工具/Agent 名称；完整记录跳转携带真实运行编号 |
| 窄屏 | 按聊天容器实际宽度判断；不足 1000px 时工作面板改为覆盖式抽屉，遮罩点击或 Escape 关闭 |

宽屏工作面板宽 288px，阈值优先保证正文空间。使用 `ResizeObserver` 响应业务侧栏、窗口等造成的容器尺寸变化，离开时释放监听。工作面板默认关闭，本轮未增加拖拽调整列宽或宽度持久化。

切换面板不会新建会话、清空输入或发送问题。打开时焦点进入面板，关闭后返回原按钮；页签支持左右方向键及 Home/End。面板出现/退出沿用轻量透明度与位移动画，支持减少动态效果。手机面板及遮罩高于历史提问浮钮，避免背景按钮遮挡资源入口。

最近执行不是实时工具控制台，也不展示思考正文、完整工具参数或输出。原会话轨迹接口仍按当前账号鉴权；刷新失败会清空旧事件，追溯链接回到当前会话，避免继续指向旧运行。未读取时明确显示空态，不补造执行节点、安装数量或工具可用状态。

## 独立 React 聊天

继续使用左会话、中间聊天、右信息面板三栏。左侧折叠后在桌面保留 56px 快捷栏，可重新展开、新建对话、打开执行追溯或返回业务系统；手机收起快捷栏以保护阅读宽度。

“助手信息”增加两个页签：“工作区”集中展示当前会话、Skills、MCP、记忆与带会话编号的追溯入口；“模型与能力”保留实际模型配置、备用顺序与角色能力。默认模型的说明仍为配置优先级，实际调用以执行记录为准。页签支持方向键、Home/End；原有 Escape 关闭及焦点返回继续适用。

两套入口的工作面板样式使用同一视觉原则：白色与浅灰面板、蓝色重点、细边界、较轻图标和阴影、清晰的内容分组。资源入口只是导航，安装、启用、人工确认及权限仍使用对应业务页面与后端接口。
