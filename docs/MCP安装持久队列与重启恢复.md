更新：2026-10-16，`java-cloud`。完善 P09 的固定安装队列，复用现有 JDBC 事务、人工确认、运行时和审计。功能默认关闭。

## 行为

启用后，本人确认安装时，在同一事务写入安装登记、原确认审计和 `QUEUED` 队列记录。事务提交前不会启动安装程序，队列写入或审计失败会一起回滚。原安装接口仍返回 202，安装完成仍须主动启用。

每个应用进程使用独立调度线程，每秒最多尝试领取一个任务，安装执行器保持单工作线程。没有本地空位时等待，不把整个数据库队列提前领到内存。后台先锁本人的注册行，再用条件更新领取 `QUEUED`，写入随机工作令牌和 `DISPATCHED` 审计；事务成功后才提交执行。两个服务同时竞争同一任务，最多一个领取成功。

领取前核对当前安装编号、状态、数据库期限及运行目标摘要，执行前重新校验账号。完成时再次锁定注册行，检查安装编号、工作令牌、状态和未过期租约，成功登记、队列完成和审计同事务提交。旧令牌、取消、过期或后续新安装均阻止迟到结果登记。

## 重启与有效期

- **等待中 `QUEUED`**：重启后读取数据库继续领取，使用原先已确认的安装编号和目标，不增加一次下载请求或新的人工授权。
- **已领取 `RUNNING`**：即使进程在领取后、实际启动程序前退出，也不自动重复执行。领取之后的外部副作用无法仅靠数据库确定，需等待租约过期并重新确认安装。
- **取消、完成或失败**：终态任务不再领取。取消登记与队列撤销在同一事务，原本进程内的中断机制继续适用。

沿用从原确认开始计算的 **15 分钟总有效期**，排队、停机和执行共同消耗该期限，领取和重启不续期。新的期限由数据库当前时间生成，查询和完成校验也使用数据库时间。

过期检查每次最多处理 50 条，和原失败审计一起提交，再尝试中断本进程的对应任务。调度器遇到过期等待任务时将其标记失败，下一轮可继续下一个账号。已领取任务在过期清理后显示 `INSTALL_LEASE_EXPIRED`；清理周期不保证刚过期就立即显示失败，但过期后的成功回写已经被拒绝。

排队超过有效期、账号失效或安装目标变化时不会继续执行。用户核对状态后重新确认来源、版本和许可证，使用新的请求编号和安装编号重试。

## 目标绑定与凭证

任务只保存账号稳定 ID、确认时用户名、安装编号、目标配置 SHA-256、队列状态及工作令牌。不保存任意命令、环境变量、模型密钥或网关凭证，也不接受用户指定执行路径。

目标摘要包含固定 Fetch 版本及包摘要、传输方式；Stdio 模式增加管理员配置的 Python 和安装器路径，网关模式增加网关地址及运行镜像配置。恢复时配置字符串变化会产生 `INSTALL_RUNTIME_CHANGED`，要求重新确认；凭证轮换本身不改变安装目标。

该摘要绑定配置值，不证明同路径脚本或同标签镜像的内容未改变。实际包摘要、文件校验、固定工具发现、受限网络和镜像治理继续由既有安装与运行规则负责。

## 页面与隔离

本人状态接口增加 `installQueue: MEMORY|DURABLE` 与 `installPhase`，只读取本人当前安装编号对应的队列记录。页面仅对明确返回的持久等待/执行状态解释恢复规则，旧服务端不显示恢复承诺。确认取消、登记移除、错误不自动重试和手机布局继续保留。

调度和过期检查使用单独的 `localMcpInstallScheduler`，避免阻塞 Agent 运行日志的定时租约更新。这里没有开放队列列表、任意任务参数、管理员替别人安装、Cron 或通用任务 API。

## 数据库与启用

先在目标业务库执行 V25，再执行 `sql/mysql/migration-V34-mcp-install-queue.sql`。AI 模块 classpath 副本为 `db/migration-V34-mcp-install-queue.sql`，内容必须相同。迁移仅新增 `agent_mcp_install_job`，使用自增主键、安装编号唯一键及 `(status,id)` 等索引，不回填或重放旧的内存任务。

确认迁移后设置：

```dotenv
AGENT_LOCAL_MCP_ENABLED=true
AGENT_MCP_DURABLE_INSTALL_ENABLED=true
```

默认关闭时不读取新表，V25 部署仍可启动；明确开启但缺少 V34 时启动失败，避免接受无法持久化的安装。现有已安装账号不需要重新安装；开启前已经丢失的内存任务不会被猜测恢复，原租约过期后需本人重新确认。

发布时配套更新前后端、执行迁移，再开启开关。多副本必须使用一致的队列模式与目标配置；当前未验收混用版本、开关或目标的滚动部署。关闭开关会停止持久任务领取；回退前应让等待任务完成或由本人取消，保留新表和审计。再次启用也不会自动重放已经领取的任务。
