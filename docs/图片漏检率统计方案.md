# 图片整图未检出率

最新补充：模型资料现也可通过原评估入口登记成功评估及整图未检出计数，派生模型未检出率，需 V62；不自动用业务任务回填，见 [字段说明](检测模型字段说明.md)。此前未新增模型评估记录描述的是上一阶段范围。

2026-10-25（UTC+8），`java-cloud`。用户已明确：“图片里面没有一个目标被检测出来”。本方案按该定义实施；此前关于标注测试集或逐图复核的数据来源问题已被此次澄清取代，不再作为本功能的前置条件。

## 已确定的统计口径

**整图未检出率 = 成功完成检测但未输出任何目标的图片数 / 成功完成检测的图片数 × 100%。**

- 任意类别检出均算检出，包含 Normal。一个目标都没有才计入分子；检出部分目标不属于本指标的整图未检出。
- 输出以该次检测阈值过滤后的结果为准；失败图片单独列出，不能当成未检出或正常。
- 例如总数 100 张，98 张检测成功，其中 3 张没有任何目标，2 张执行失败：整图未检出率为 `3 / 98 = 3.06%`，不是 `3 / 100`。
- 该指标描述模型输出，不需要真实标签，也不能证明真实目标被漏检。AP 与有真实标注的目标漏检率仍是不同指标，不从 AP 推算。

## 当前实现

检测结果快照、检测记录卡片和任务追溯概览共用 `NoDetectionSummary.vue`，计算使用 `noDetectionPresentation.js`。资料由现有、按账号鉴权的结果和追溯接口提供，本轮没有新接口、数据库字段或业务写入。

现有 Kafka Worker 对成功推理的逐图结果统计 `statistics.noDetectionImages`，并提供 `successfulImages`、`failedImages`、`totalImages`。未检出张数与成功数从同一结果快照读取；不使用列表其他任务的数据拼接分母，不按分类计数、置信度或历史比例猜测。

展示规则：

| 情况 | 显示 |
| --- | --- |
| 成功数大于零、未检出数为零 | `0.00%` |
| 所有成功图片均未检出 | `100.00%` |
| 无成功图片 | 无法统计，失败不作为未检出 |
| 未提供未检出数或成功数 | 未记录 |
| 无效计数、未检出数超过成功数、重复字段不一致或总数对不上 | 待核对 |
| 任务尚未结束或没有可核对的结束状态 | 待完成 |

正常比例同时展示分子、分母和失败张数，可用键盘展开统计说明。数字不补造零，缺失值不转为百分比。前端只是只读展示，未修改现有检测、复核、放行或报告审批流程。

## 历史字段与范围

旧 `missDetectionRate` 存在按置信度、不同分母及不同单位记录的情况；Kafka Worker 旧值也包含失败数作为分母。本轮不覆盖历史资料，不直接复用或改名该字段，不以其均值形成首页 KPI。快照中的旧值仍留在历史原始资料内供核对。

当前实现为单任务统计。未新增首页跨任务汇总、模型评估记录或批量导出指标。若后续增加汇总，必须在同一模型、阈值及完整数据范围内先合计有效计数再相除，不能平均各任务百分比。
