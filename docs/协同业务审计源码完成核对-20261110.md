# 协同业务审计源码完成核对

核对基线：单体 `java-cloud` 的 `3b996ce8`。本页记录一次有界源码审核及最小补齐，不代表 ECS 测试、迁移或生产发布通过。未启动应用、数据库、浏览器、测试或 ECS；表结构仍为原29张目标表。

| 设计要求 | 实际生产源码依据 | 本轮结论及修复 |
| --- | --- | --- |
| A03 具体操作者、操作时身份、真实字段差异 | `BusinessMutationAudit` 在写入前核对并锁定当前操作者，按唯一 `BusinessMutationParticipant` 读取真实前后快照；`OperationsAuditPersistence.OperationV2` 保留操作时身份 | 机制已有；补齐43个已登记检测字段及账号权限字段的中文标签，避免新历史只显示数据库列名。旧事件不改写 |
| A04/A06/A07 版本并发、精确重放、相同编号不同内容冲突 | `BusinessCommandStore` 在原 `workflow_instance` 保存规范化摘要、原结果和回执；`BusinessMutationAudit` 同事务校验版本、写业务及必要审计。报告另用既有 `REPORT_COMMAND` | 通用机制已有；报告之前仅写 V2 审计而未返回审计响应头，已补真实 `appendChangeWithReceipt`，重放先验证原命令摘要及当前资源权限，再查询原审计回执。不会以审计查询替代业务幂等 |
| A08 审计失败回滚业务、版本及命令 | 通用事务切面、报告 `finish`、`AiCollaborationHistory.record` 及 `DetectionSystemChanges` 均在必要审计失败时抛错 | 保持；报告首响应缺有效审计回执时同样抛错，旧命令原审计缺失则409，不创建替代事件或编号 |
| A16 旧历史、改名/删账号、资源删除 | `OperationV1` 不补造角色/字段；V2保留操作时身份，`JdbcMutationSnapshots` 固化关系显示值；`OperationsAuditService` 每次按当前资源权限决定详情或摘要 | 已有明确实现；账号版本选择器 `result.accountVersion` 补入严格元数据白名单。读取姓名、密码等任意属性仍被拒绝。账号管理自身的开关守卫未改动，不能将这次白名单修复解读为原 off 配置必然发生业务失败 |
| A17 秘密、附件、大结果有界 | 各模块显式字段白名单；设备联系方式脱敏，模型路径/验证原文只记秘密变更；检测系统只留结果登记标记及 SHA，AI只接收登记过的公开事实和秘密变更标志 | 未发现本轮必须重写的生产接线；继续使用现有标量/字段数/总字节上限，不复制整份结果、请求体或解密配置 |
| A18 版本分派及29表约束 | `OperationsAuditPersistence` 向 `JdbcAuditStore` 显式登记 V1/V2/V3，原 compact SQL/构建器约束对应载荷；SYSTEM 使用空人类执行者及独立系统来源 | 修复一条过期回归：V3已经登记，未知版本应使用4，不能继续期待 V3 返回“未登记”。未增加表、DDL旁路或弱化未知字段检查 |
| A19 持久化与重启后可读 | 业务、`audit_event`、原命令回执共用 JDBC 事务；历史读取由持久化版本分派恢复；提交后通知独立于数据库事实 | 源码机制已有；真实重启及回滚仍必须通过原 Jenkins/ECS 完整验收，不以编译替代 |
| SYSTEM 与 AI 审计覆盖 | `DetectionSystemChanges` 接 worker 完成/失败和本地异步执行；`AiCollaborationHistory` 接配置、企业额度、申请及个人额度生产服务 | 已有真实调用链、操作来源和必要审计回滚；本轮未做机械重写或增加其他平台 |

报告回执仅在 `operations.audit.enabled=true` 且 `collaboration.change-history.enabled` 或 `collaboration.mutations.enabled` 至少一项为 true 时要求新版审计端口。原审计开启但两项协同开关关闭时仍使用原 V1 `append`；审计关闭时保持原分支，不给既有 off 路径额外增加新版回执依赖。新回执响应头为 `X-Resource-Version`、`X-Audit-ID`、`X-Change-Event-ID`。旧报告后来被编辑时，精确重放仍返回原命令的业务版本和审计编号。

回归源码增量：`AuditMetadataTest` 4→5；`DetectionCollaborationMySqlTest` 11→13；`BusinessFieldChangesTest` 数量不变，仅修正未知版本断言。另在既有真实报告编辑用例中核对首次与重试的三项响应头，既有领取差异用例核对中文标签。登记由主分支统一更新。

本地检查限于跳过测试的 Maven `test-compile`、源码标签目录静态核对及补丁检查。所有新增用例仍须先提交推送固定源码，再由本地 Jenkins 调度 ECS 执行。
