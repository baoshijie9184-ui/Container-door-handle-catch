# Agent 会话模型切换

更新日期：2026-10-21，UTC+8。适用分支：`java-cloud`。

主站 Vue 聊天和独立 React/AG-UI 入口均可在输入框下方的“使用模型”下拉框选择服务端已配置的模型，不需要用户填写 Key 或 API 地址。

## 使用方式

1. 打开本人会话，在输入框底部选择模型。选项同时显示模型名称及供应商，避免将百炼托管和供应商直连混淆。
2. 等待“已保存，仅对当前会话的新任务生效”后发送消息。服务端保存选择，刷新后仍保留。
3. 选择“系统默认 · 模型名称”可取消本会话覆盖，后续新任务跟随系统默认配置。选择不会改变其他会话、其他账号或系统配置。
4. 当前任务运行、暂停或等待交互时，其模型已固定，任务结束后才能切换。专业子任务沿用任务的模型快照。切换不会重写历史回答。
5. 发生网络异常或版本冲突时，点击“核对模型选择”读取当前服务端结果，再决定是否切换。核对不重发 POST，不清空草稿或附件。
6. 历史选择不再出现在可用目录时，界面明确显示原模型已不可用，可选择目录中的其他模型。

模型目录中“已配置”表示服务端具备连接配置，不保证供应商当前可用或仍有免费额度。启用备用链时，请求失败可能转入备用模型；实际调用以执行轨迹和用量记录为准。

## 实现边界

- 复用 `GET /agui/models` 和 `GET/POST /api/agent/conversations/{sessionId}/model-selection`，不增加新的管理接口或数据库迁移。
- 选择按本人会话保存；每次重新鉴权，使用服务端模型白名单、请求编号去重及版本检查。敏感业务操作仍走原确认流程。
- Vue 和 React 共用 `ComposerResources`，显示默认模型、供应商、保存反馈、不可用选项及只读核对结果。切换会话时丢弃迟到响应，避免覆盖当前会话。
- 交互参考项目内 DeepSeek Harness 的模型路由选择；沿用 AgentScope Java 2.0.4，不引入其运行框架或新依赖。
