## 配置与兼容

同一供应商的多个模型复用原 Key、网关及账号权限。每个供应商最多登记 16 个不同名称，各自维护熔断状态。浏览器只能选服务端登记的模型，Vue/React 继续读取原目录接口，不暴露地址或凭据。

```dotenv
AGENTSCOPE_AI_MODEL=dashscope:qwen3.8-flash
DASHSCOPE_MODEL=qwen3.8-flash
DASHSCOPE_ADDITIONAL_MODELS=qwen3.8-max-0902,deepseek-v4.1-flash,glm-5.3
AGENT_MODEL_FALLBACK_ENABLED=true
AGENT_MODEL_FALLBACK_MODELS=dashscope:qwen3.8-flash
AGENT_MODEL_ADDITIONAL_FALLBACK_MODELS=dashscope:qwen3.8-max-0902,dashscope:deepseek-v4.1-flash,dashscope:glm-5.3
MEM0_LLM_MODEL=glm-5.3
```

基础备用列表仅含旧镜像也能登记的主模型。新版追加扩展备用并去重；旧镜像忽略扩展变量，回滚不会因新增模型 ID 无法启动。原灵算和 DeepSeek 直连保留手动选择，不参与新配置的自动备用链。Key 未进入仓库。

百炼 `403 AllocationQuota.FreeTierOnly` 归额度问题并触发切换、冷却；普通 403 仍为认证错误。仅切换尚未输出内容的请求，不重跑工具。所有免费候选都不可用时返回失败，不自动转入原付费模型。

Qwen 3.x 显式设置 `enable_thinking=false`，兼容强制工具选择和非流式调用；该参数不发给其他模型。依据为[百炼 Function Calling](https://docs.modelstudio.console.alibabacloud.com/en/model-studio/qwen-function-calling)和[错误码文档](https://www.alibabacloud.com/help/en/model-studio/error-code)。
