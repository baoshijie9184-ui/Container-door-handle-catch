# 业务表单浮层与校验视觉收尾

2026-10-25 UTC+8，java-cloud，当前未提交源码。范围为实际路由的设备编辑、人员编辑、账号与组织，以及共用表单浮层样式。沿用现有 Element Plus、接口和权限，不增加依赖。

## 已修正

1. 320px 下日期面板原宽 322px，右边超出视口，整页宽度达到 329px。设备维护时间和人员入职日期现通过独立 popper 类限制宽度，320px 时为 296px；日历内容跟随可用宽度，未使用隐藏整页溢出来掩盖内容。日期、时间格式及 UTC+8 说明保留。
2. 长部门名原将下拉框撑到约 474px。设备、人员表单和组织员工关联使用共用 business-select-popper，按视口限制宽度，长候选自动换行。320px 观察宽度为 296px，桌面最多 560px，原搜索、候选值和选择处理保留；没有截断选项正文或扩大查询范围。
3. 人员资料与部门候选并行读取时，部门初始校验可能先于候选到达，成功读取后仍残留“请先重新读取部门候选”。现在候选读取完成并更新视图后，仅重新校验已有部门字段。有效原部门不再残留旧提示；缺失部门仍显示需重新选择，读取失败仍显示读取错误。未改变表单保存、唯一性查询、版本核对、账号变化保护及离开确认。
