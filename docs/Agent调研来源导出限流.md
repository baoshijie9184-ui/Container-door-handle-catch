# Agent 调研来源导出限流

调研来源导出增加可选的账号限额。启用后，同一账号的所有运行、会话和后端实例共用一个数据库计数，默认在一个 60 秒固定窗口内允许生成 5 份文件。其他账号独立计数，读取来源不计入额度。

## 行为与边界

首次成功导出开启时间窗，到期后的下一次成功导出重新开启。达到上限返回 HTTP 429、`Retry-After` 整数秒及 `Cache-Control: no-store`，不返回附件或导出编号。前端显示经过校验的等待秒数，保留重新确认流程，不定时重试、不自动下载，也不展示服务端异常原文。

这是固定窗口计数，窗口边界附近可能连续完成两批请求，不承诺任意滚动 60 秒最多 5 次。它限制成功生成并提交审计的文件数量，不替代网关对恶意请求、失败请求及连接数的限制。

服务端先核对本人运行，再通过账号主键行锁串行分配额度；在取得锁后读取数据库时间，并重新授权读取来源，过滤等待期间已过期的内容。计数、文件生成及 V33 摘要审计使用同一事务。编码、大小检查或审计失败均回滚计数，不交付文件；数据库故障不会自动降级为不限流。事务超时沿用导出服务的 15 秒设置。

服务器成功提交后若浏览器断网，额度和审计仍保留，因为文件已生成；重新确认会使用新额度及导出编号。审计不证明用户已保存文件，哈希不证明来源结论真实。

## 迁移与启用

已有 V16、V31、V33 的 MySQL 8 环境，在备份并核对目标库后执行：

```sql
SOURCE /path/to/sql/mysql/migration-V35-agent-research-export-limit.sql;
```

V35 只新增 `agent_research_export_limit`，每个导出账号一行，含账号主键、窗口到期时间和成功次数。无正文、地址或历史明细，不扫描审计表；读写以账号主键定位。AI 模块的 classpath 副本与归档 SQL 保持一致，不自动执行迁移。

```dotenv
AGENT_RUN_JOURNAL_ENABLED=true
AGENT_RESEARCH_EVIDENCE_ENABLED=true
AGENT_RESEARCH_EXPORT_ENABLED=true
AGENT_RESEARCH_EXPORT_RATE_LIMIT_ENABLED=true
AGENT_RESEARCH_EXPORT_MAX_PER_WINDOW=5
AGENT_RESEARCH_EXPORT_WINDOW_SECONDS=60
```

限流开关默认 false，旧部署关闭时不读取 V35 表。来源、导出、限流三个开关同时开启才装配限流服务；缺表或参数越界会阻止启用。次数范围 1—100，窗口范围 1—3600 秒。多实例必须共用主库并保持相同参数；修改参数重启后，已有窗口的截止时间保留，新的次数上限立即生效，下一窗口使用新的时长。应用重启保留当前计数。

跨域部署默认暴露 `Retry-After`；如自行覆盖 CORS 响应头列表，需保留此头及 `X-Export-Id,X-Content-SHA256`。旧前端收到 429 仍会进入原有失败提示，新前端读取不到合法等待秒数时显示稍后重试，不解析任意服务端正文。

回退将限流开关设为 false 并重启，恢复原导出行为，保留计数表和审计。如果需要停止导出，应关闭 `AGENT_RESEARCH_EXPORT_ENABLED`。不删除旧表、不清理已下载文件。
