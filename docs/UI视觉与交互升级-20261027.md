# UI 视觉与交互升级

2026-10-27，按用户要求对现有 Vue 主站与独立 React Agent 进行视觉和交互升级。保留现有技术栈、业务流程、路由、API、权限、数据处理和状态管理；没有服务器发布或演示数据写入。

## 设计与实现

采用白色内容面、浅灰导航、深色文字和蓝色操作色。状态色仅用于业务状态、警示与错误；减少大面积渐变、卡片阴影和无意义装饰。沿用现有系统字体与图标，不下载字体、不安装新 UI 框架。

| 范围 | 本轮实现 |
|---|---|
| 公共规范 | 在现有 `design-tokens.css` 中统一颜色、字号、间距、内容宽度、控件高度、圆角与阴影；继续供 Vue 和 React 共用 |
| 应用布局 | 精简重复的布局样式，统一紧凑页顶、232px 业务侧栏和内容留白；导航选中项增加细蓝色定位线，收起、移动导航、账号菜单与面包屑行为保留 |
| 首页 | 将原有标题、说明和三项操作移到页面入口；历史累计改为纯白双栏、年度单色刻度和分隔数据组，保留登记口径与年度明细；质量待办与资源数据减少独立盒子堆叠 |
| 业务页面 | 统一 `PageHero` 标题与操作区、列表统计带、筛选工具栏、表格密度、表单焦点和分节；知识库、额度及日报复用现有标题组件 |
| 弹层与状态 | 统一对话框、抽屉、输入控件、空状态、加载图标与错误提示；禁用按钮与可用按钮保持可区分的视觉状态，不改变禁用条件 |
| Agent 两入口 | 统一历史栏、页顶、阅读宽度、欢迎区、快捷入口和输入容器；减少彩色图标块、重阴影与嵌套盒子；保留会话、资源、上下文、排队与模型选择原逻辑 |
| 登录与悬浮操作 | 登录页沿用项目原有门把手示意图，调整品牌、字体与比例；悬浮助手改为紧凑入口并复用开源图标，错开回到顶部按钮，保留拖拽及位置保存 |
| 响应式与可访问性 | 修复旧手机端 `flex-direction` 与页头换行冲突造成的操作越界、辅助链接挤压、320px 额度数字断行；保留键盘焦点、既有弹窗关闭、表格局部滚动及减少动态效果 |

未引入新的主题覆盖文件。主要调整在既有公共样式、布局及公共组件中完成，页面只做必要的布局与样式修改。

开源复用以项目已安装的 Element Plus 2.10.2、Ant Design 5.29.3 及现有图标为基础，包声明均为 MIT，保留原有依赖和许可文件。没有复制 Linear、Vercel、Notion 的产品代码、品牌或素材。

## 业务边界核对

本轮修改前保存了 UI 文件快照，并对全部 124 个 Vue 组件的 `<script>` 内容计算摘要。修改后脚本摘要全部一致；本轮修改文件的事件与 `v-model` 表达式也一致。React `main.jsx` 与快照比较，仅主题中的文字/边框颜色发生变化，组件逻辑和事件处理未变。

新增 `PageHero` 使用、标题语义、图标与辅助访问属性均属于展示层调整；首页原操作使用原路由和处理函数。没有改动依赖声明、后端、接口地址、权限、状态转换或业务数据。

本地快照和边界回执位于 `work/ui-upgrade-20261027/baseline/`、`logic-boundary.json`。
