# 业务审计覆盖与文件交付

日期：2026-10-22，UTC+8。分支：`java-cloud`。

本轮新增实现代码，未编译、测试、构建、迁移或部署，未启用生产开关。本文列出代码覆盖范围及缺口，不是验收报告；此前局部检查不能替代本轮验证。

## 业务资源与必要审计

现有 `BusinessMutation` 切面继续以同一数据库事务保存业务变更和必要元数据审计。新增受限的资源、请求编号、整数版本和范围选择器，只读取编号/版本白名单，不序列化整个实体，不执行用户提供的表达式，也不读取提示词、凭证、电话、备注或文件正文。

创建后的编号可以来自返回对象或已经回填主键的参数，不再将对象参数一律记成 `collection`。只有明确声明的批量操作才能使用集合标识。无法取得实际资源编号时拒绝提交；明确未创建成功的布尔结果可记录 `not-created/NO_CHANGE`，不伪造新资源。未提供整数版本时为 null，页面显示未知，不将模型的语义版本字符串强转为数字。

已有 HTTP 请求编号会复用并回传，命令正文声明的编号不得与请求头冲突；旧入口没有编号时生成服务端关联编号。相同请求下的多个业务审计共享关联编号。这不是对所有旧 CRUD 接口新增了命令幂等：未接入命令回执的旧写接口仍不能据此宣称可安全重发。

| 业务域 | 本轮代码覆盖 |
| --- | --- |
| 员工 EMPLOYEE | 新建、修改、删除、分配设备；对象参数使用实际员工 ID，已提供的乐观锁版本入审计 |
| 设备 DEVICE / DEVICE_USAGE | 新建、修改、删除、解除员工关联、员工侧设备归还及设备使用记录变更 |
| 设备告警 DEVICE_ALERT | 确认及解决，数据库变化与必要审计同事务 |
| 组织 ORGANIZATION | 部门创建记录生成的部门 ID；账号绑定记录目标账号 ID 和实际绑定版本，不误记为操作者账号 |
| 检测 DETECTION | 沿用创建、上传确认、流转、分派、复核、处置、返工及重试审计；创建编号从实际响应读取 |
| 检测模型 DETECTION_MODEL | 沿用元数据修改、发布、默认与删除记录，补充评估、发布策略、停用、归档及校验入口 |
| 报告 QUALITY_REPORT | 新建、编辑、提交、撤回、修订、独立审批及人工事件重投，复用业务命令编号与报告版本 |

报告审计在新命令的业务事务内追加，重复请求先返回原始已保存结果，不重复治理报告。草稿审计为 `PRIVATE`，已进入业务流转的元数据为 `ENTERPRISE`；主管只能查看企业记录和本人私有记录，不通过新审计入口看到他人的私人草稿或会话资料。

## 文件交付状态

新增 V52 的 `operations_file_delivery`，每次 HTTP 响应单独生成不可预测的交付编号，另存原请求关联编号。记录账号 ID、范围、业务域、资源/文件编号、已有版本、预期长度、服务端已返回写调用的字节下界、HTTP 状态及时间；不保存原始文件名、服务器路径、签名地址或文件内容。

| 状态 | 可以说明的事实 |
| --- | --- |
| AUTHORIZED | 原业务鉴权已经通过，必要授权审计已提交，尚未记录正文写出 |
| HEAD_AUTHORIZED / HEAD_COMPLETED | 仅响应头请求已授权 / 服务端处理返回，无文件正文，不声称客户端收到 |
| STREAMING | 首次正文写出前的必要审计已提交 |
| SERVER_COMPLETED | 同步 HTTP 处理返回，已观测的写调用无异常；已知长度时按实际响应核对。不能证明浏览器收到或保存 |
| INTERRUPTED | 观测到写出异常、处理失败或已知长度不一致；异常调用中可能已经部分写出 |
| UNKNOWN | 进程/结束回执中断、缓冲区重置或异步状态无法核实；不能据此声称零传输 |
| REDIRECT_AUTHORIZED | 已登记外部读取授权并准备重定向；不观测浏览器与 OSS 之间的实际传输 |

交付切面在原 Controller 完成资源鉴权后、Spring 写出响应体之前登记。Filter 包装输出流计数，不把整份文件复制进内存，也不记录内容。授权审计失败时不交付文件；首块写出前的必要审计失败也阻止正文写出。

结束状态和必要审计同事务。若结束记录暂不可保存，保留原授权/写出状态；后台仅把超过 15 分钟无法核实的记录标为未知，不自动重发下载。已授权请求的迟到结束可以继续记录，即使账号已经退出或撤权，这只是记录原响应的事实，不授予新的访问权限。

字节字段是服务端写调用的记录下界，可能只包含完整返回的写调用，不是客户端接收量、压缩后的公网流量或费用依据。206 表示部分响应。对于未知/写出中记录，0 只是现有记录下界，不能解释成没有传输。

## 已接入入口与页面

- 会话文件下载、JPEG/PNG 预览及 PDF 页预览：按本人会话及文件重新鉴权，交付审计为 `PRIVATE`。
- Agent 业务资料读取：继续通过原业务文件门面鉴权；本入口的访问审计按私人 Agent 使用记录隔离。OSS 图片重定向只登记授权，不冒充传输完成。
- 已审批报告导出：仍由原报告服务鉴权和冻结快照检查，交付元数据为企业业务记录，不改变独立审批规则。
- 旧本地原图、标注、检测结果及模型下载：新增 contracts 权限门面、实际任务/模型编号、写出前重新鉴权及 HEAD 状态；未登记模型文件拒绝，旧未登记上传改为 410。详见 [历史入口交付审计](历史文件入口权限与交付审计.md)。
- `GET /api/operations/audit/deliveries`：扩展原审计查询入口，员工看本人，主管看企业及本人私有交付，返回白名单 DTO，不返回路径或凭证。
- Vue 原审计页面增加交付表及资源版本的未知提示；React 侧栏链接到同一个审计页面，不创建另一套审计权限规则。所有时间按 UTC+8 显示，保留键盘按钮和减少动态效果设置。

`OPERATIONS_FILE_DELIVERY_AUDIT_ENABLED=false` 为独立默认值，需要先启用 `OPERATIONS_AUDIT_ENABLED` 并完成 V40/V52。根 SQL 与 System 模块 classpath 均保存 V52 副本；没有在任何数据库执行迁移。

实现复用现有 Spring AOP、Jakarta Servlet 与 JDBC，不引入第三方业务执行框架。Spring 代理不会拦截同类内部调用，因此只给内部被调用的方法加注解不等于覆盖所有入口；后续旧路由接入必须沿实际 HTTP 与服务代理路径核对。参考 [Spring AOP 官方说明](https://docs.spring.io/spring-framework/reference/core/aop/proxying.html)。
