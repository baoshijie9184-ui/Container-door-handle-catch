## 模型和调用边界

本人已登录控制台的模型详情当前显示：`BAAI/bge-m3` 输入价格为零，1024 维，8K 上下文；当前 L0 最高为 2,000 请求/分钟、500,000 tokens/分钟。这是核对当日的价格和速率，不承诺平台永久免费或无限调用。[模型控制台](https://cloud.siliconflow.cn/me/models)、[官方价格](https://www.siliconflow.cn/pricing)、[Embedding API](https://siliconflow.readme.io/reference/createembedding)。

项目固定使用以下配置，不自动选择带 `Pro/` 前缀的型号，不回退其他供应商；服务异常、凭据无效或限流时按原记忆错误处理流程返回。平台未来若调整这一型号的价格，应用固定型号本身不能替代供应商的计费规则，需重新核对价格。

```dotenv
EMBEDDING_PROFILE=siliconflow-bge-m3-v1
EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_MODEL=BAAI/bge-m3
EMBEDDING_REQUESTS_PER_MINUTE=60
EMBEDDING_MAX_INPUT_BYTES=8000
EMBEDDING_BATCH_SIZE=8
```

请求串行且不等待排队，SDK 重试为零；每次最多 8 条，单次方法调用最多 64 条，每条限制 8,000 UTF-8 字节，超限在发送前拒绝。这个字节上限用于短期记忆的保守准入，不等同于模型的 token 上下文上限。接入显式保存 1024 维配置，向 BGE-M3 API 请求中不发送 OpenAI 的可变 `dimensions` 参数，并验证返回条数、索引、维度、有限数值和模型名。

密钥位于本地 Jenkins Credentials，ID 为 `doorhandle-siliconflow-embedding`。流水线通过 SSH 标准输入写入本轮 ECS 的私有临时文件，测试容器只读挂载，随后删除并核实不存在。密钥不进 Git、镜像、命令行参数或归档。应用可用独立的 `EMBEDDING_API_KEY`，或私有绝对文件 `EMBEDDING_API_KEY_FILE`；两者必须且只能配置一个，不复用 LLM 密钥。
