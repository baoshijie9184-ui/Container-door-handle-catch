# 工作台跨进程恢复与文件 MySQL 验收

2026-10-18（UTC+8），`java-cloud`，AgentScope Java 2.0.4。沿用现有单体工作台、状态存储、文件服务和 V37/V38 迁移，不引入新执行框架或生产迁移。

## 环境与范围

使用 ECS 已有 MySQL 8.4.11 中独立的随机测试库，连接仅通过本机专用 SSH 隧道。每轮创建只授权该库的临时账号；数据库管理密码不复制到开发机。测试与被中断的独立 JVM 均将 MySQL 会话时区设为 `+08:00`，与生产配置约定一致。

跨进程测试确实调用 `Runtime.halt`，不执行 Java close/finally，模拟执行进程突然退出；恢复端重新创建服务及 SDK，读取同一个 MySQL 状态库。执行进程位于 Windows 开发机，数据库位于 ECS；不是本轮重启生产后端，也不是云端完整应用/Jenkins 重启验收。模型、身份和 App 门面为合成替身，副作用仅为隔离测试表的一行数据，没有真实业务写入或供应商调用。

## 六个进程中断切点

| 切点 | 已验证行为 |
| --- | --- |
| 模型请求前 | 保存的 SDK 状态可供明确恢复；无写入效果，不自动继续 |
| 写工具体执行前 | 工具结果未知，恢复保持拒绝；不能因测试表为空就猜测外部操作未开始 |
| 用户问题等待中 | 原问题和等待状态保留；明确回答后才进入可调度状态 |
| 专业子任务模型请求中 | 退出前断言父任务 WAITING_CHILD、子任务 RUNNING；恢复后子任务 NEEDS_REVIEW，需明确恢复 |
| 工具效果及结果均完成后 | 两个不同请求争用同一恢复版本仅一个成功；两个服务争用执行领取也仅一个成功；恢复后的真实 SDK 读到原工具结果，工具体不重放，原回执不改写，效果仍仅一行 |
| 写入效果完成但结果尚未登记 | 保留 UNKNOWN 工具记录，主任务 NEEDS_REVIEW；恢复被拒绝，不自动重放，原效果仅一行 |

已完成结果的恢复不只检查状态：实际重新运行 SDK，让模型读取原工具结果后返回恢复完成文本，核对只发生一次新模型调用、新执行尝试编号，以及工具体调用次数为零。

首轮为 5/6：旧探针工具调用没有补齐参数 JSON，`start_background_task` 校验失败后在主 Agent 退出，未到达预定子任务切点。现按实际 SDK 输入构造参数，并在退出前校验父子状态；没有更改期望来掩盖失败。基线失败保存在 `work/workbench-crash-baseline-20261018/`，诊断日志为 `work/workbench-child-cut-diagnostic.log`。修正后的六项均通过，报告为 `work/workbench-crash-verified-20261018/report.json`，完整日志 `work/workbench-crash-mysql-strengthened-20261018.log`。

## 文件工作区

App 文件服务与真实 MySQL、JUnit 私有磁盘目录联调。两个独立服务实例共享数据库和文件目录，验证最后一份账号配额只有一个上传成功、六次并发相同请求仅产生一份文件和一条创建审计；另一账号配额独立。其他检查覆盖会话/账号隔离、请求冲突、恶意文件名、格式拒绝、PDF 文字层和新鲜权限、字节篡改、预览截断、审计失败回滚及 Fork 切点文件引用。

首组 11 项全部通过，报告 `work/workspace-mysql-verified-20261018/report.json`，日志 `work/workspace-files-mysql-20261018.log`。这些是 App 服务层检查，账号/会话门面为合成样本；不是生产 HTTP/JWT、两套浏览器入口或真实模型理解能力验收。

补充后的同版本完整文件组为 12/12，包含 PNG、JPEG、WebP、PDF、TXT、Markdown、CSV、JSON、HTML 和 SVG 十种真实样本。上传实例与读取实例分离，核对原始字节、SHA-256、中文及扩展字符文件名、每种格式的跨账号拒绝；PDF 文字层和实际 PNG 预览均验证，HTML/SVG 仅纯文本，图片明确没有视觉/OCR。报告 `work/workspace-all-formats-mysql-verified-20261018/report.json`，日志 `work/workspace-all-formats-mysql-20261018.log`。测试使用真实图片编码器及 WebP 样本、独立构造的 PDF 字节，不以文件后缀或上传返回值代替再次从数据库/磁盘读取。

两轮隔离库、账号、专用隧道以及独立构建中的私有配置副本已清理；分别保留清理回执。只读查询再核对两个库和账号均不存在，端口 13308 已关闭。测试账号仅有自己随机库的 schema 授权，原管理密码未离开服务器。
