# 项目开发规则

本文件规定本项目的开发、验证提速、去重、发布及失败恢复规则。执行环境、凭据和 ECS 约定继续遵循根目录 [AGENTS.md](../AGENTS.md)。具体改造及实际结果见 [本地 Jenkins CI/CD](本地Jenkins-CICD.md)。

## 先完成全部开发，再统一提交验收

- 同一轮按“全部约定功能及代码整合 → 本地跳测试构建 → 提交并推送固定版本 → Jenkins 在 ECS 统一测试验收 → 通过后上线”执行。
- “全部整合”包括业务代码、数据库迁移、Redis 缓存、配置、前后端接线、测试代码、验证流程、发布、取消和失败恢复，不以某一个功能完成代替整轮开发完成。
- 开发阶段仅做只读排查、静态检查、编译及跳测试打包，不提前运行本地或 ECS 测试。不在整合中途零碎提交、推送或触发验证；先核对 SCM 自动触发规则。
- 失败后先汇总已知问题，集中修复相关代码、调用方、配置和夹具，再按影响范围统一复测，禁止“修一个、跑一轮”。

## 验证效率、证据复用与发布

- 一次整合对应一个固定提交、明确输入和一轮统一验收。参数、配置、映射、夹具接线与来源兼容检查放在同一流水线的耗时阶段之前；开发阶段仍只做静态检查和跳测试构建，不借“快速检查”提前运行测试。
- 同一固定提交、输入、验收范围和制品已有完整有效证据时，不因进入发布阶段、重复触发或查询状态重新运行全量验收。先核对活动任务和已有回执，禁止同时启动相同验收；失败、取消或缺证据不得当作通过。改变输入或修复代码后，先说明受影响范围，再统一复测。
- 控制检查优先作为同轮流水线的前置阶段，不为每个小修改另起验证任务；同轮复用控制结果必须绑定原始报告和实际执行条件，不能仅按测试名称跳过。维护按已授权且证据闭合的安全批次集中执行，不为每个文件或输出单独开构建；尺寸、引用、权限或证据边界确需分批时记录原因，不为减少构建编号放宽安全门。
- 完整发布采用“同轮自动验收 → 用户确认同一候选 → 临时验收资源 STOPPED → 消费本轮证据发布”的闭环，不另起一轮相同业务验收。提交、输入、范围、制品或证据不一致时拒绝发布；不得跨版本拼接局部 PASS。正式停写、源数据新鲜检查、备份、迁移、生产健康与数据读回仍须执行，不能用测试证据替代。 正式 MySQL 从维护窗内的新鲜源重新迁移并验证，不把数小时前的候选数据库覆盖生产，也不要求正常业务从验收开始一直停写；复用旧候选原生数据卷时，仍须核实对应来源内容未变。
- 优化数据库测试先消除重复建表和初始化，再考虑合并执行或有界并发。仅在显式隔离合同下复用普通数据用例的表结构，每例重新准备数据、连接和服务并确认异步任务退出；DDL、触发器、崩溃、备份恢复等用例保持所需独立环境。保留已有夹具默认行为，不用统一事务回滚、删用例或降低断言换取速度。
- 每轮保留阶段耗时，并区分构建、数据库准备、用例执行、恢复、收证与清理。优先修复实测瓶颈；耗时异常或失败后先分析已有日志，不通过重复整轮运行试探原因，不把预计节省时间写成实测结果。
- 取消必须绑定本轮身份，按“请求远端正常取消 → 等待原执行终态和证据 → 清理自有临时资源”收尾，不能只断开 SSH 或提前停止夹具。发布失败时，只有确认新库进程从未启动且旧源未变，才可受控恢复旧服务；新库可能已有写入时保留新库与证据，走同目标恢复或前向修复，禁止切回旧库写者。结果以实际健康和数据读回为准。

## 生成物先记账，再按清单回收

- 区分 Git／D 盘源码原件、SQL 和恢复资料、原始报告与 ECS 运输副本、编译产物和隔离测试数据。每轮记录拥有者、路径、大小、保留依据和收尾结果；未闭合的临时资源明确交接，不让失败轮次无主累积。
- 已获授权的重复运输包，仅在完整原件摘要、已结束且未发布、精确路径、无活动引用且无现用静态来源依赖均核实后，沿现有 Jenkins 集中清理；不删除源码目录或 SQL，不全局 prune。静态依赖包括共享工具镜像原始安装者、已登记收尾及恢复证明的来源输入；没有进程打开不等于无人使用。已有消费者仍读取 ECS 原路径时，先保留该副本，不能只凭 D 盘另有相同字节就删除，也不能删后绕过证明。
- 统一验收前核对现有可用空间、已知阶段需求与可回收量，优先处理有证据的重复产物；不把 CI 历史积累直接转为扩盘请求，也不承诺一次快照能覆盖未知峰值。

## 完成标准

- 完成必须有对应固定版本的实际验收与发布回执；“代码写完”“编译通过”“部分测试通过”不能等同可上线。
- 保留完整验收范围和原始报告。当前结果、未执行检查、真实失败及下一步须如实说明，不把预计性能收益写成实测结果。
- 上线前保全旧库、原始 SQL、必要恢复点和数据读回依据；测试后只清理本轮自有临时资源，业务服务、Jenkins 和 ECS 按现有约定保持运行。
