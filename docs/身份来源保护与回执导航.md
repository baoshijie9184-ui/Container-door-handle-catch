## 已有 ID 也可能需要核对

旧数据的 ID 与名称对齐，只能证明字段一致，不能证明当初由谁明确建立关联。新增 V56：`detection_identity_binding_event` 保存不可变来源事件，`detection_identity_binding` 指向当前事件，`detection_identity_source_control` 保存来源保护阶段。没有来源的历史记录不自动补认。

| 来源 | 记录条件 |
| --- | --- |
| `NEW_CREATION` | 本次创建事务已经保存创建人 ID，重新鉴权并锁定实际创建账号 |
| `QUALITY_ASSIGNMENT` | 当前主管明确分派，任务已保存选定员工 ID；来源与 V54 使用同一请求编号 |
| `PERFORMED_OPERATION` | 复核、处置或返工的实际执行账号，与刚保存的人员 ID 一致 |
| `SUPERVISOR_MAPPING` | 新 V55 批次及逐条映射存在，主管、请求、任务、职责、目标 ID 与历史名称匹配 |
| `OBSERVED_CLEAR` | 业务字段已经清空，撤销当前来源；记录系统观察，不伪造人工操作人 |

所有来源写入都要求现有业务事务，重新锁定真实任务和相关账号，保存事件与当前指针；人工来源同时保存必要业务审计。失败回滚原业务变更。Agent 创建使用原创建命令的请求编号，后台线程不凭用户名构造操作人。来源指针、前一摘要、修订和事件摘要构成关联记录，摘要不是外部签名，也不是独立的防篡改审计服务。

同一任务、职责、请求只允许同一来源状态；重复请求不能把指针退回更早事件。来源损坏或缺少对应事件时停止继续写入，不删除证据、自动修复或补造历史。

## 先收集，再明确启用

`DETECTION_IDENTITY_EVIDENCE_ENABLED=false` 默认关闭，依赖稳定身份服务、回填确认、必要审计及 V40/V55/V56。开启后初始阶段为 `COLLECTING`：收集新操作和主管新确认，预览显示待核对来源，当前授权模式保持原阶段，不会自动切换。

主管明确激活时，检查所有任务创建人和非空责任人都有匹配来源，并重新锁定必要账号。未完成时拒绝激活；通过后同事务推进 V40 控制修订、身份授权模式和来源模式 `ACTIVE`，保存激活审计与命令回执。请求显式携带是否启用来源保护，并绑定该范围和预览版本；旧启用请求不能代替新增范围的确认。

来源保护激活后，员工授权同时要求稳定账号 ID、历史名称快照，以及当前来源事件与任务 ID/职责/人员关联一致。该限制通过原检测权限策略进入任务、统计、报告与文件读取；主管仍按当前企业业务权限工作。来源模式异常或与主授权模式冲突时拒绝降为用户名授权。

通用后台同步只对已经清空的字段登记失效观察，不根据同名账号重建来源。旧版本修改人员字段导致来源不匹配时，页面显示待核对，激活状态下员工不能凭不匹配来源继续访问。已经存在的 V55 老批次也不会在开启功能时自动变成新来源，需必要的主管新确认。

## 页面与刷新

账号关联页面展示“实际创建操作”“实际分派操作”“实际人工操作”“主管回填确认”或待核对状态；旧来源与当前字段不同会单独提示。来源读取按一页任务批量查询，不为每条职责单独查询来源。

新增同一路径下的只读 `/api/detection/identity/batches`，支持主管游标查看批次；原 `commands/{request}` 返回批次、数量、摘要、确认人及对应映射明细，数量不一致时拒绝报告成功。普通员工无权读取这些企业身份资料。

页面可从批次列表查看明细，也能手动输入原请求编号核对。地址只保留请求编号，刷新后仅重新鉴权、查询回执；不保存映射正文、恢复旧授权或发送写请求。暂未查到回执不代表原操作终止；页面不会根据新选项自动重做未知请求。原页面仍在时，可明确重试保存的同一请求、内容和版本。

未提交的选择和未知请求正文没有写入浏览器存储，刷新后不能重建原确认。需要继续核对时使用原编号及服务器回执；若要新的映射，必须重新预览并明确确认。服务端控制版本及请求去重仍负责并发保护。时间由服务器明确返回 UTC+8 偏移，页面复用北京时间格式化工具。

## 发布与剩余工作

镜像新增 `io.doorhandle.identity-evidence=1`。发布保护检查 V56 必要列、来源记录及模式；持久 pin 增加 evidence 维度，兼容读取旧三/四维 pin。存在来源记录或已启用来源保护后，不能关闭相应读取/授权能力或回到不支持的镜像。首次写入仍须先准备兼容恢复基线；声明与元数据门禁不是实际验收成绩。

V56 根目录与 Detection classpath 使用同一迁移文本，默认只建立空表和收集阶段，不执行历史回填或自动激活。尚未运行任何 SQL。
