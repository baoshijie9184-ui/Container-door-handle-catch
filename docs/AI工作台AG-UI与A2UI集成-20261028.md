# AI 工作台 AG-UI、A2UI 与 Spark Design 集成

2026-10-28，本轮仅修改本地工作台及相关 Java 模块，没有提交、推送、数据库迁移、Jenkins/Docker/ECS 配置修改或生产发布。没有进行真实模型请求或写入业务演示数据。

## 已核对的依赖与原有缺口

后端仍使用 Spring Boot 和 AgentScope Java 2.0.4；主站保留 Vue 3。独立工作台实际安装版本为 React/React DOM 18.3.1、`@agentscope-ai/chat` 1.1.72、`@agentscope-ai/design` 1.0.32、Ant Design 5.29.3、Vite 6.4.3、Lucide React 1.40.0。没有新增依赖、替换框架或修改锁文件。

沿用现有开源组件及许可：React、Spark Design、Ant Design、Vite 为 MIT，Spark Chat 为 Apache-2.0，Lucide React 包声明为 ISC。没有复制商业产品代码或下载新字体。

原来 `/agui/run` 只转发回答文本和业务引用，前端只拼接文字；`A2uiSurface.jsx` 没有接入聊天，且使用的单包 `v1.0/createSurface.components` 结构不能当作完整 A2UI 实现。原工作台启用排队控制后还会通过持久会话入口处理消息，因此不能只修改 SSE 消费器。

本轮实现参考 [AG-UI 官方事件说明](https://docs.ag-ui.com/concepts/events)、[A2UI 0.9.1 协议](https://a2ui.org/specification/v0.9.1-a2ui/) 和 [Spark Design 官方仓库](https://github.com/agentscope-ai/agentscope-spark-design)，不假设上游所有协议能力已经接入项目。

## 通信与动态结果链路

保留 `/agui/run`、已有 SSE、账号鉴权、主/专业 Agent 执行及服务端持久会话。没有让浏览器覆盖历史、工具、身份或模型状态。

后端从实际中间件的 `TOOL_STARTED/TOOL_COMPLETED/TOOL_ERROR/TOOL_CANCELLED` 回执转发工具生命周期，携带原调用编号。模型提出工具调用的文字或 `ToolUseBlock` 不再被用来证明工具实际执行成功。完成工具参数传输仅显示等待返回；工具返回不等于业务审批成功。

前端支持运行开始/结束/异常、消息开始/增量/结束、多消息、工具开始/参数结束/返回、步骤开始/结束及版本化自定义事件。工具参数和模型内部推理不混入回答正文。未知事件降级忽略，不执行不受控状态补丁。

SSE 处理覆盖 UTF-8 跨块、LF/CRLF/CR、多行 `data`、注释心跳、异常帧、终止帧和 AbortSignal；消息、正文和事件长度均有上限。流式 Markdown 更新按动画帧合并。每轮临时消息使用独立编号，连续断流不会覆盖上一轮残留正文。

原 `/agui/run` 在持久回复保存后发送业务引用，并使用 `CUSTOM/doorhandle.a2ui.v1` 携带逐条 A2UI 消息；动态结果读取失败时仍能完成正文和既有业务引用。历史及排队会话通过同一动态结果组件重新读取当前授权数据。

新增接口均返回 `Cache-Control: no-store`：

| 接口 | 用途 | 执行边界 |
|---|---|---|
| `POST /agui/ui/resolve` | 接收 `sessionId` 和既有 `AgentCards.Reference[]`，返回版本、目录编号及 A2UI 消息数组 | 先验证本人会话，再经现有业务卡片门面读取当前权限范围；不调用模型、不执行业务写操作 |
| `POST /agui/ui/actions` | 接收同一会话、引用及 `action`，准备后续用户问题 | 必须带 `X-Agent-Action: a2ui`；重新验证会话、资源、界面和组件来源；仅返回受控普通用户问题 |

`FOLLOW_UP` 交互包含 `name/surfaceId/sourceComponentId/timestamp/context`，上下文只允许当前引用编号及 1–500 字问题。前端将服务端准备的问题提交给原聊天发送函数：排队启用时走原持久输入入口，否则仍走 `/agui/run`。提交未确认时保留输入并显示错误，不自动重试。`REFRESH` 映射为重新读取动态结果，不重新调用模型。

会话所有权验证通过 `AgentChatSessionApi.assertOwned` 和 App 原有会话服务完成；不要求开启可选文件/工作台服务。AI 关闭时不注册新动态界面服务及控制器，相关上下文装配已有测试。

## A2UI 范围与扩展方式

本轮采用 **A2UI 0.9.1 包络子集**及项目自有目录 `urn:doorhandle:a2ui:workspace:1`。目录标识不触发外部下载，不宣称覆盖完整官方 Basic Catalog。

支持四类包络：`createSurface`、`updateComponents`、`updateDataModel`、`deleteSurface`；组件定义和数据分开更新。支持绝对 JSON Pointer 数据绑定、根对象替换、字段删除、输入双向绑定、渐进占位和局部更新。

白名单共 13 类：`Text`、`Column`、`Row`、`Card`、`Metric`、`DataTable`、`BarChart`、`TextField`、`Form`、`Button`、`Tabs`、`Progress`、`Status`。图表支持条目选择、键盘聚焦和数值提示；进度来自实际图片处理计数，不代表推测的 Agent 完成比例。

校验覆盖目录/版本、包络字段、组件属性和编号、重复编号、循环引用、深度与数量限制、数据路径、危险原型键及数组越界。禁止任意 HTML、脚本、URL 组件、函数调用和动态求值。未知组件显示占位，坏界面不会替换已接收正文。刷新后只合并用户编辑的输入字段，不让旧表单数据盖住新统计值。

服务器当前根据已验证的业务引用生成布局和数据，不开放模型任意输出组件树。扩展组件时须同步登记客户端属性校验、渲染注册表及服务端投影/动作白名单，并增加正反例测试。

## 界面与兼容

继续使用 Spark Chat 的 `Bubble`、`Sender`、`Markdown`，接入 Spark Design ConfigProvider、输入、按钮、表格、选项卡、状态和进度组件。启用匹配 Ant Design 5 的 CSS 变量主题；Lucide 图标向 Spark Button 明确传递数值 `iconSize`，避免字符串尺寸进入 SVG。

统一角色标识、实际消息时间、生成/中断/错误状态、正文复制、代码块排版、白蓝配色与焦点反馈。欢迎区为四项业务入口的 Bento 布局，结果区使用统计带、表格/图表切换和跟进表单。动态组件按需加载，尊重减少动态效果设置。

执行面板使用实际 SSE 回执；持久排队执行使用本人已有运行事件接口补读。未收到的调用、结果、步骤和完成比例均不合成。会话切换会取消旧读取并清理旧状态。

保留附件、技能、模型选择、会话历史、排队/暂停/取消、工作台面板和业务路由。结果区可展开原业务卡片，保留既有设备/模型/报告完整信息及操作入口。旧后端没有动态接口时回退原卡片；权限撤销时清除旧界面，网络异常时保留快照并明确提示。
