它是围绕 DeepSeek Harness 构建的自托管企业 Agent 平台，包含对话/研究、企业知识库、文档处理、生成文件、Skills/MCP、任务治理及管理后台。技术组成是 Vue 3、FastAPI、Node DSH Runtime Host、MongoDB、Redis、Weaviate；默认 Compose 包含 12 个服务。README 要求至少 8 GB 可用内存和 20 GB 可用磁盘。浏览器 Agent、代码 Agent 依赖另行分发的闭源桌面客户端，并非仓库 Web 端自带的完整能力。依据：[README](https://github.com/himovo/movo/blob/main/README.md)、[部署配置](https://github.com/himovo/movo/blob/main/docker-compose.yml)。

当前 Java 单体可参考其任务执行展示、文件交付及管理台组织方式。其 [ActionReceipt](https://github.com/himovo/movo/blob/main/services/chat-api/app/governance/action_receipt.py) 将执行状态、幂等键、结果引用和证据一起建模；与本项目正在完善的真实执行回执校验方向相关。两者底层运行时和持久化不同，适合逐项比较产品交互及边界，不能把整个 MOVO 当作可直接替换的 AgentScope 组件。
