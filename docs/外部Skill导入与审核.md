# Skill ZIP 上传功能已移除

按用户要求，已移除上传界面、外部来源列表与工具映射接口、ZIP 解析和外部来源创建服务。资源市场仍提供官方平台导航，当前没有自动下载 Skill 的能力。

新技能仅允许使用本人明确授权的成功业务运行作为来源，继续经过规则 Eval、独立主管审核、原生读取和版本治理，见 [Agent 技能自学习与受控发布](Agent技能自学习与受控发布.md)。

历史外部上传记录、原文、许可证和审计数据保留，不删除数据库内容。历史外部版本仅供按原有权限查看或停用，不再修订、评测、发布、回退启用及运行时加载。已存在的 V24 表和版本来源列继续保留用于历史兼容。

移除的入口：`POST /api/agent/skills/imports`、外部来源列表和 `GET /api/agent/skills/imports/tool-options`。旧地址在身份校验后统一返回 HTTP 410（功能已移除），不解析包、不保存或读取上传来源。普通草稿 API 不再接受 `sourceImportId`；后台创建也执行相同校验。

验证：完整 `mvn -B clean verify` 成功，417 项中 401 项通过、16 项显式集成检查跳过，0 失败或错误。旧地址 HTTP 410 修正后，技能与 MCP 的 28 项定向检查再次通过；主站 47 项检查与生产构建通过。实际浏览器/HTTP 验收 8 项通过，覆盖上传入口消失、旧地址拒绝、草稿绕过拒绝、历史只读、市场导航、MCP 保留、主管手机页面及匿名保护。项目已重新启动，六项服务健康检查通过。验收脚本为 `scripts/diagnostics/skill_upload_removal_acceptance.py`，结果位于 `work/skill-upload-removal-acceptance.json`；不调用收费模型，不修改业务数据。

2026-10-14：新增公开 LINK 下载来源已接入，见 [链接下载与受控安装](外部Skill链接下载与受控安装.md)。该能力不恢复旧 ZIP 上传接口，也不恢复历史 EXTERNAL_UPLOAD 版本；LINK 采用下载器核验的固定提交、清单和文件摘要。
