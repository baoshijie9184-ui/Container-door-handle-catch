## 实际修正

### 关闭排队的可见反馈

此前从更多菜单关闭排队后，本地偏好已保存为 off，但当前队列区域没有提示，已有两条消息仍显示，容易误以为没有生效。Vue 与 React 现于有积压且关闭排队时显示“消息排队已关闭”和“开启排队”，数量说明为“已有 N 条消息待处理”。提示只出现在原队列可见时，空队列不增加提示栏；任务操作窗口继续保留原设置入口。

这只是既有本地排队设置的反馈，没有修改调度、消息交付、取消、引导或权限。重新开启仍调用原 setQueueEnabled，既有消息保留。

### 减少动态效果时的浮层定位

React 在减少动画模式下通过键盘或鼠标打开排队菜单时，菜单 DOM 存在，但 top 实际为 -8440px，导致不可点击。延长等待未解决；单独接入组件库 motion 配置也没有修复定位。

本地已安装的 @rc-component/trigger 会临时将浮层定位归零并读取几何数据。旧全局规则将每个元素的 transition-duration 改为非零的 .01ms，这也给原本无需过渡的定位坐标引入了过渡：调试中设置 top=0 后立即测量，仍得到 -8440px。

Vue 的 system-ui.css 与 React 的 styles.css 在减少动画模式下现使用 0s 的过渡时间；React 根 ConfigProvider 也沿用现有 useReducedMotion 接入 token.motion。普通模式保持原有动效时长。复核时菜单 top 为 658px、菜单项位于视口内，临时归零后立即读取也得到 0px，不再停在旧坐标。

组件库配置依据 [Ant Design 官方主题配置](https://ant.design/docs/react/customize-theme/)，并核对了本机安装版本的 MotionWrapper 与 trigger 定位实现。没有修改 node_modules、升级组件库或新增依赖；原有版权声明保留。未用固定坐标覆盖浮层位置，也未通过强制点击绕过问题。

## 本轮观察

### 历史阅读、回到最新与长代码

用 12 轮隔离样例补查历史阅读：主站与 React 在 390px 减少动画、1440px 普通动画下，阅读第五轮时追加执行输出、队列由两条增至三条，并开关工作面板。四批中选定段落相对消息区的偏移均保持不变；手动回到最新后，后续输出保持贴底。样例更新只改变被拦截的 GET 响应，不提交消息，不执行真实任务。

发现并修复了另一个键盘问题：原“回到最新消息”按钮消失后焦点落到 BODY，PageUp 不再作用于聊天区。两入口现仅在用户点击或键盘激活该按钮时，将焦点交给已有的消息阅读区，且使用 preventScroll；发送消息及新输出路径不增加焦点移动。复核中 PageUp 能上翻约一屏，后续输出不再将该阅读位置拉回底部，返回最新提示正常重新出现。

React 的已安装 Markdown 高亮组件在外层 pre 中包含一个真正的代码 pre。旧增强逻辑给二者都设置了阅读类和 Tab 停靠，形成内外两层代码滚动。现将外层标为非滚动框架，保留语言栏、原复制/下载按钮和原渲染器，仅正文 pre 获得限高、局部滚动与阅读名称。流式结构变化时仅移除增强层自己添加的 Tab/标签，不改组件原生属性。未修改 node_modules；既有 @agentscope-ai/chat 的 Apache-2.0 许可保留，无新依赖。

长内容样例包含 30 行表格与 JSON 代码。两入口窄屏的表格和正文代码均能通过 PageDown、方向键进行局部滚动，整页没有横向溢出；React 单个代码块只保留一个增强阅读区，不再让外层抢占 Tab。没有点击复制或下载，不宣称剪贴板及文件交付已验收。

同时清理 agent-appearance.css、agent-unified.css 中残留的减少动画非零过渡规则，避免覆盖此前的 0s 修复。修正前两端窄屏消息区计算值仍为 1e-05s，修正后为 0s；普通动画不变。新增 40 张有效隔离画面，原 before 与 React 代码框架修正前的观察保留为定位资料，不加入最终批次。

### 会话导航补充收尾

Vue 全屏聊天在 640px 以下不再为已折叠的会话栏保留第二条空白栏。沿用原会话展开按钮，将其放到标题区，隐藏窄屏下的装饰头像；桌面与业务页助手抽屉的布局不变。320px 样例的输入区宽度由此前 202px 增至 244px，390px 为 314px。会话展开仍覆盖聊天区，Escape 后回到原按钮；两种宽度均没有整页横向溢出。

另复现了两入口在窄屏选择历史会话后焦点落到 BODY 的问题。Vue 选择会话、点击遮罩或 Escape 收起时统一返回原会话按钮。React 相同路径返回头部会话按钮；桌面切换会话时也返回该按钮，防止原会话行在加载期间被禁用而丢失焦点，桌面历史栏保持展开。使用 preventScroll，避免为焦点回移额外滚动聊天。原读取、账号范围、会话请求及确认流程均未改动。

补充 6 张 Vue 320/390px 展开与 Escape 画面、14 张两入口 390/1440px 切换与键盘画面。实际观察到会话标题切换、焦点所在元素、后续 Tab 目标和遮罩关闭后的焦点；没有提交消息或业务写入。Vue 桌面保留会话行焦点，React 桌面保持会话栏展开并聚焦头部按钮。这不等同全部弹层焦点管理或真实账号隔离验收。
