# MCP 原生协议发布与回滚保护

2026-10-22 UTC+8，`java-cloud`。当前仅新增/修改源码与说明，未运行脚本、编译、测试、构建、迁移、Jenkins 或云端操作。

当前 V59/V60 源码将协议声明扩展为 4，覆盖共享镜像封存、独立法律归档、部署恢复镜像引用与一次性回收。运行器升级已接入发布/回滚和隔离演练源码，见 [升级与镜像保留](MCP运行器升级与部署镜像保留.md)。原生协议 2、旧共享协议 3 仍保留读取；实际下限取历史、pin 和潜在写入者的最高值。未运行或验收；下文协议 2 的描述针对最初原生保护阶段。

## 需要保护的状态

V49/V58 的原生固定 Fetch 使用两个私有 journal、持久执行编号、安装 pool、逐安装额度与退出回执。应用回滚必须保留其读取、撤销与核对语义，不能仅根据旧 JVM 不存在就释放子进程占用，也不能恢复旧安装器后重新执行未知安装。

保留现有 AgentScope Java 与模块化单体。新增 `script/docker/mcp-compat.py`，复用现有部署元数据读取、私有状态文件和 MySQL 卷绑定方法；不在 AI 服务中跨模块读取业务表。此脚本只查固定 MCP 元数据和镜像声明，写私有发布 pin/回执，不启动工具、不迁移、不操作 Docker 资源。

## 新执行暂停

`AGENT_MCP_WRITES_ENABLED` 默认 true，沿用原环境行为。设为 false 时：

- 拒绝新安装确认、新启用、SDK 连接检查和 Fetch 调用，持久安装调度器不再领取等待任务。
- V59 同时暂停新的共享镜像回收，保留已经提交的回收只读核对。
- 工具目录不再把 Fetch 作为当前可用工具；运行时也检查同一开关，不能只绕过页面按钮调用。
- 保留本人查询、停用、取消、执行终止核对及已有目录的受控管理。
- 不伪造正在运行的任务已经退出；仍须已有回执协议收尾。等待任务的原到期时间不延期，到期按未领取规则处理。

该开关是部署配置，修改后随应用配置生效，不是浏览器动态开关。它暂停新的受控执行，不是把整个数据库变为只读，也不替代业务权限与人工确认。

页面显示暂停提示，关闭新安装、连接检查与启用按钮，保留停用和核对入口。独立 React 沿用现有 MCP 管理跳转。

## 镜像声明、数据下限与恢复基线

后端 Dockerfile 新增 `io.doorhandle.mcp-native-protocol="2"`。无标签按 0 处理；不会把旧镜像补写标签当成兼容证据。

发布前读取：

1. MySQL 的 STDIO 执行回执、V58 原生安装 worker 与原生额度快照，包括已完成历史；检查未知 transport、缺失快照及待退出资源。
2. 当前容器和目标 Compose 是否可能产生新的原生持久状态。
3. 与项目、实际 MySQL 命名卷及创建代次绑定的私有 `mcp-native-protocol-pin.json`。
4. 当前、目标镜像的原生协议声明，以及原生功能所需的迁移列、执行账本、队列、核对开关和安装额度。

最终下限取上述数据、pin 与潜在写入者的最大值。native 状态对应下限 2；未产生或启用 native 协议时为 0。下限不会因为关闭写入、清理一个安装或换镜像而自动降低。V58 新列本身不是开启功能的证明。

存在待退出原生执行时，目标必须保留 STDIO、固定进程控制和持久回执；存在待核对原生安装时，还须保留监督器及安装核对入口。仅关闭新执行不能关闭这些读取与核对能力。已经完成的历史仍需可读，不能借关闭 MCP 模块隐藏记录。

首次启用原生写入前，当前恢复基线也必须声明相同协议。可先准备经过独立验收的兼容镜像，暂停新执行，再在最终候选阶段开启；不允许只有候选懂新数据，而唯一回滚镜像不懂。若账户已经留有新协议数据而恢复镜像没有声明，守卫会拒绝激活，保留现有容器和证据，需要先处理兼容基线，不能自动绕过。

镜像标签及本脚本只是声明与元数据检查，回执标记 `declarationOnly: true`。它们不证明 SDK 行为、内核权限、真实升级或回滚可用；最终恢复演练仍是必需验收项。

## Jenkins 接线

- `pipeline.ps1` 将新守卫与现有依赖一起传输；本轮没有执行传输。
- `deploy-remote.sh` 在停止应用前、持有同一部署锁时检查并保存 MCP 协议下限；发布和回滚都经过 `activate`。
- 实际镜像快照额外保存当前 `AGENT_MCP_WRITES_ENABLED`。恢复暂停基线时，快照覆盖较新的环境配置，避免恢复后默默重新开放执行。旧镜像的 legacy 状态不伪装成支持暂停。
- 隔离演练在首次启动、升级、回滚和候选恢复前调用同一守卫；显式兼容基线必须支持暂停与协议读取，回滚阶段保持其暂停值。演练还拒绝候选镜像冒充独立旧版证据。
- 私有 `mcp-transition.json`、Jenkins 元数据归档及部署摘要记录下限、镜像、写入开关与声明性状态，不包含账号、聊天、URL、凭证或 journal 路径。

此改动没有新增数据库迁移或执行任何迁移。保留 V58、原数据库、Agent 卷及 journal。不能删除 pin 或清空资源记录来绕过兼容约束。
